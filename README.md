## 一、项目简介

本项目实现了一个**轻量化、可实时运行**的人体动作（肢体语言）识别系统。它从视频中提取人体骨架关键点，用一个轻量时空图卷积网络（ST-GCN + 创新模块 CA-AGC）识别动作类别，并能在低端显卡（如 RTX 3050）上实时运行。

系统目前支持四个动作：**打招呼（Greeting）、握手（Handshake）、拥抱（Hug）、拒绝（Reject）**，并预留了"新增动作只需加一个文件夹"的可扩展接口，方便后续补充更多动作后重新训练。

整个流程分四步：**数据预处理 → 模型训练 → 模型测试评估 → 实时识别演示**，另外还提供一个**留一交叉验证**脚本用于小数据集的可信评估。

### 核心特点

- **轻量化**：模型参数量仅约 0.41 M，分类网络单样本推理约 2 ms，在 GPU 上等效处理能力数万 FPS，瓶颈仅在骨架提取，可在 RTX 3050 实时运行。
- **骨架驱动**：基于 MediaPipe Pose 的 33 个关键点，对背景、衣着、光照变化鲁棒，且天然保护隐私（不存原始画面）。
- **创新模块 CA-AGC**：置信度感知的自适应图卷积，利用姿态估计器输出的关节可见度动态调整图结构（详见第七节）。
- **可扩展**：新增动作类别零代码改动，只需新建文件夹放视频。
- **可复现**：全局随机种子固定，配置集中在单一 `config.py`。
- **中文显示无乱码**：已专门处理 matplotlib 与 OpenCV 的中文/负号显示问题。


输出：`outputs/cv_confusion_matrix.png`、`outputs/cv_per_class_metrics.png`、`outputs/cv_metrics.json`、`outputs/cross_val.log`。

## 六、算法设计与流程（写论文用）

### 6.1 整体流程

```
视频 → MediaPipe骨架提取 → 归一化(平移/尺度不变) → 时间重采样(统一64帧)
     → 数据增强(仅训练) → 特征组装(坐标+运动) → 轻量ST-GCN+CA-AGC → 动作类别
```

### 6.2 骨架提取

使用 MediaPipe Pose 提取 33 个人体关键点，每个点输出 `(x, y, visibility)`：`x, y` 是归一化到 [0,1] 的图像坐标，`visibility` 是该关键点的可见度/置信度（创新模块会用到）。相比直接用 RGB 像素，骨架表示更轻量、对外观变化更鲁棒，也更利于隐私保护。

### 6.3 预处理与归一化

- **平移不变**：每帧以髋部中心为原点。
- **尺度不变**：以躯干长度（肩-髋距离）为尺度归一化，消除人体大小/远近差异。
- **时间归一化**：把任意长度的视频统一重采样到 64 帧（`CLIP_LEN`），训练时带随机时间抖动。

### 6.4 数据增强（仅训练集）

旋转（±10°）、缩放（±10%）、平移、关节高斯噪声、随机关节遮挡。**水平镜像已关闭**——因为打招呼和拒绝都是"手臂上抬+左右摆动"，镜像会破坏方向语义，反而加重二者混淆（这是实验得到的结论）。

### 6.5 网络结构

轻量 ST-GCN 主干，由 4 个时空图卷积块组成，每块 = 空间图卷积（含 CA-AGC）+ 时间卷积 + 残差连接，通道配置 `[64,64,128,128]`，时间维在第 3 块下采样。最后全局池化接全连接分类。整体参数量约 0.41 M。

训练采用 AdamW 优化器、标签平滑、权重衰减正则、warmup（前 5 轮）+ 余弦退火学习率调度，这套组合在小数据集上训练更平稳。

## 七、创新点：CA-AGC（置信度感知的自适应图卷积）

> Confidence-Aware Adaptive Graph Convolution
> 对应代码：`model.py` 中的 `CAAGConv` 类。

本节是论文的核心贡献章节，从研究动机、与现有方法对比、数学形式化、前向流程、复杂度、与增强协同、消融设计七个方面系统阐述。

### 7.1 研究动机

人体动作识别的图卷积网络（GCN）把人体骨架建模成一张图：关节是节点，骨骼是边。图卷积通过"邻接矩阵"把相邻关节的特征聚合起来。然而现有方法存在一个被长期忽视的问题：

**邻接矩阵对所有关节一视同仁，完全忽略了"每个关节的定位质量是不一样的"这一事实。**

姿态估计器（如 MediaPipe）在输出每个关节坐标的同时，还会给出一个**可见度/置信度 `visibility`**，表示"这个关节这一帧到底测得准不准"。在真实手势交互中，定位不可靠的情况非常普遍：

- **握手**：手臂伸向镜头，发生强烈的透视形变与自遮挡；
- **拥抱**：双臂交叉环抱，大量关节被身体或对方遮挡；
- **快速挥手 / 拒绝**：手部高速运动产生运动模糊，定位抖动。

此时若仍把低置信度（很可能定位错误）的关节与高置信度关节同等聚合，**错误信息会沿着图的边扩散污染整个特征**，降低识别精度。传统做法把 `visibility` 直接丢弃，等于浪费了姿态估计器免费提供的、关于"数据可靠性"的宝贵先验。

**核心思想**：让图卷积"知道"哪些关节可信，在聚合时**自动削弱不可靠关节的影响**，把注意力集中到可靠关节上。这就是 CA-AGC。

### 7.2 与现有图卷积方法的对比

| 方法 | 邻接矩阵形式 | 是否用关节置信度 | 是否逐帧自适应 |
|---|---|---|---|
| 原始 ST-GCN | 固定静态图 `A` | 否 | 否（整段视频共享一张图） |
| 自适应 GCN（如 2s-AGCN） | `A + B`（B 可学习） | 否 | 否（B 训练后固定） |
| **CA-AGC（本文）** | `RowNorm(A ⊙ G(t)) + B` | **是** | **是（随每帧置信度变化）** |

CA-AGC 在自适应 GCN 的基础上，额外引入了一个**随每一帧动态变化、由置信度驱动的门控项 `G(t)`**，这是它与已有方法的本质区别：已有方法的图在推理时是"静止"的，而 CA-AGC 的图会**随着每一帧关节质量的变化而实时呼吸**。

### 7.3 数学形式化

#### 符号定义

- `N`：批大小（batch size）
- `C_in / C_out`：输入 / 输出特征通道数
- `T`：时间帧数（序列长度）
- `V`：关节数（本项目 `V = 33`）
- `x ∈ ℝ^{N×C_in×T×V}`：输入特征张量（坐标、速度等）
- `c ∈ ℝ^{N×T×V}`：关节置信度（取自 MediaPipe 的 visibility，范围 [0,1]）
- `A ∈ ℝ^{V×V}`：对称归一化的**静态邻接矩阵**，`A = D^{-1/2}(Ã+I)D^{-1/2}`，其中 `Ã` 是骨骼连接、`I` 是自连接、`D` 是度矩阵（在 `graph.py` 中构造）
- `B ∈ ℝ^{V×V}`：**可学习的自适应邻接项**，初始化为全 0（初始时模型等价于纯静态图，训练中逐步学出数据驱动的连接）
- `Θ`：1×1 卷积的特征变换（`nn.Conv2d(C_in, C_out, 1)`）

#### 第一步：特征变换

先用 1×1 卷积把输入特征投影到输出通道空间：

```
h = Θ(x),   h ∈ ℝ^{N×C_out×T×V}
```

#### 第二步：构造置信度门控矩阵 G(t)

对第 `t` 帧，关节 `i` 与关节 `j` 之间的门控权重定义为二者置信度的几何平均：

```
G_ij(t) = sqrt( c_i(t) · c_j(t) )
```

写成张量形式（`cs = sqrt(c)`，再做外积）：

```
G(t) = cs(t) ⊗ cs(t)^T,   G ∈ ℝ^{N×T×V×V}
```

直觉：只有当边的**两端关节都可信**时，`G_ij` 才接近 1；只要有一端不可信（置信度低），这条边就被显著削弱。几何平均比算术平均更"严格"——一端为 0 则整条边归零。

#### 第三步：门控 + 行归一化 + 叠加自适应项

把静态图与门控矩阵逐元素相乘，得到"被置信度调制过的图"，再做行归一化保证每个节点聚合权重之和稳定，最后叠加可学习自适应项：

```
Ã_gated(t) = A ⊙ G(t)                          （逐元素门控，⊙ 为 Hadamard 积）
Â_gated(t) = Ã_gated(t) / Σ_w Ã_gated(t)_{·,w}  （沿最后一维行归一化）
A_eff(t)   = Â_gated(t) + B                      （叠加自适应项）
```

其中 `A_eff(t) ∈ ℝ^{N×T×V×V}` 就是**该帧实际生效的、动态的邻接矩阵**。

#### 第四步：图聚合

用逐帧的有效邻接矩阵对变换后的特征做空间聚合（爱因斯坦求和）：

```
out_{n,c,t,w} = Σ_v h_{n,c,t,v} · A_eff(t)_{n,t,v,w}
```

即代码中的 `torch.einsum("nctv,ntvw->nctw", h, A_eff)`，输出 `out ∈ ℝ^{N×C_out×T×V}`。

#### 输入 / 输出小结

| 项 | 形状 | 含义 |
|---|---|---|
| 输入 `x` | `[N, C_in, T, V]` | 关节特征（坐标+速度） |
| 输入 `conf` | `[N, 1, T, V]` | 关节置信度 |
| 输出 `out` | `[N, C_out, T, V]` | 经置信度感知聚合后的特征 |

输出张量随后送入 BatchNorm、时间卷积 TCN 与残差连接，构成一个完整的 ST-GCN 块。置信度 `conf` 在时间维下采样时会随之对齐（`STGCNBlock._down_conf`），保证每一层都能拿到与当前分辨率匹配的置信度。

### 7.4 前向传播完整流程

```
          x[N,C_in,T,V]            conf[N,1,T,V]
                │                        │
          1×1 Conv (Θ)                   │
                │                        ▼
          h[N,C_out,T,V]      G(t)=√c ⊗ √c   →  A⊙G(t) → 行归一化 → +B
                │                        │
                └──────── einsum 图聚合 ──┘
                          │
                    out[N,C_out,T,V]
                          │
                  BN → ReLU → TCN(时间卷积) → +残差 → ReLU
                          │
                    送入下一个 ST-GCN 块
```

### 7.5 计算复杂度分析

CA-AGC 相对原始图卷积**几乎不增加计算量**，这正是它适合低端显卡的关键：

- 门控矩阵 `G(t)` 仅需一次外积（`O(N·T·V²)`），`V=33` 时 `V²≈1089`，量级极小；
- 行归一化是一次逐元素除法，可忽略；
- `B` 是 `V×V = 33×33 = 1089` 个参数，相对全网 0.41 M 参数可忽略；
- 置信度直接来自 MediaPipe，**无需任何额外网络或前向开销**。

因此 CA-AGC 在带来"质量感知"能力的同时，保持了模型的轻量与实时性。

### 7.6 与数据增强的协同设计

CA-AGC 与训练时的**随机关节遮挡增强**（`config.AUG_JOINT_MASK_PROB`，默认 0.10）天然协同：增强阶段随机把一部分关节的置信度置 0，模拟真实遮挡；CA-AGC 则在前向中学会"当某些关节置信度为 0 时，自动绕开它们聚合特征"。二者配合，使模型对真实场景中的关节缺失更鲁棒。这是一种"数据层制造不可靠 + 模型层学会应对不可靠"的闭环设计。

### 7.7 消融实验设计与发现

在 `config.py` 中设 `USE_CA_AGC = False` 即可关闭门控（退化为 `A + B` 的自适应图），与 `True` 各训练评估一次即构成消融对比。

**实验发现**：在当前数据集上，开启与关闭 CA-AGC 指标几乎一致。根本原因可由 7.3 的公式直接解释——当前私有数据集在理想条件（正面、无遮挡、光照良好）下录制，MediaPipe 检测率达 100%，几乎所有关节置信度 `c ≈ 1`，于是门控 `G_ij = sqrt(c_i·c_j) ≈ 1`，`A ⊙ G ≈ A`，CA-AGC 退化为普通图卷积，自然看不出差异。

**这恰恰从反面验证了 CA-AGC 的作用机理与适用边界**：它的增益与"数据中存在多少不可靠关节"正相关。这是一个诚实且有理论支撑的论文结论。当补充更贴近现实的数据（侧面视角、肢体遮挡、运动模糊、多人交叉），置信度将出现明显的高低分布，CA-AGC 的优势预计显现。这也指明了本项目的"未来工作"方向。

> 若希望现在就让消融实验出现差异，可调大 `config.AUG_JOINT_MASK_PROB`（如 0.3），主动注入遮挡，让置信度门控发挥作用，从而在实验上观测到 CA-AGC 带来的鲁棒性增益。

### 7.8 创新点小结（论文可直接引用的表述）

> 本文提出置信度感知的自适应图卷积（CA-AGC），首次将姿态估计器输出的关节可见度引入时空图卷积的邻接矩阵构造中。通过置信度几何平均门控 `G_ij(t)=√(c_i c_j)`、行归一化与可学习自适应项的组合，CA-AGC 使骨架图的连接结构能够随每一帧的关节定位质量动态调整，在几乎不增加计算量（仅一次外积与逐元素运算，无额外参数网络）的前提下，提升了模型对遮挡、运动模糊等不可靠关节的鲁棒性，契合低端设备实时部署需求。

## 八、当前实验结果与解读

### 8.1 模型复杂度与速度

| 指标 | 数值 |
|---|---|
| 参数量 | 约 0.41 M（413,584） |
| 分类网络推理 | 约 2 ms/样本（CUDA） |
| 等效处理能力 | 数万 FPS（分类网络部分） |

实时瓶颈在 MediaPipe 骨架提取而非分类网络，整体在 RTX 3050 上可实时运行。若 3050 上偏卡，可把 `config.POSE_MODEL_COMPLEXITY` 从 1 改为 0（lite 模型）提速。

### 8.2 留一交叉验证（LOVO，N=16）

| 类别 | Precision | Recall | F1 |
|---|---|---|---|
| Greeting | 0.29 | 0.50 | 0.36 |
| Handshake | 1.00 | 1.00 | 1.00 |
| Hug | 1.00 | 0.75 | 0.86 |
| Reject | 0.00 | 0.00 | 0.00 |
| **总体准确率** | | | **0.5625** |

### 8.3 结果解读（重要）

- **Handshake、Hug 表现优秀**（F1 = 1.00 / 0.86），证明模型与整套流程是健康有效的。
- **误差几乎全部集中在 Greeting ↔ Reject 这一对**：打招呼（挥手）与拒绝（摆手）在骨架运动层面高度相似，都是"手臂上抬 + 左右摆动"。在每类仅 3 个训练视频的极小数据规模下，模型难以学到稳定的区分边界。
- **这不是代码缺陷，而是数据的客观难度 + 数据规模限制。** 当前规模下 LOVO 约 56% 已是合理水平。

### 8.4 提升方向

1. **补充数据（最有效）**：每类视频从 4 个增加到 8–10 个，尤其多录 Greeting/Reject 在不同视角、距离、幅度下的样本，LOVO 准确率有望上 85%+。
2. **针对难类对增强**：可引入手部朝向、手掌前伸/后摆等更具方向性的特征。
3. **真实遮挡数据**：补充带遮挡的数据后，CA-AGC 消融差异将显现，强化创新点说服力（见 7.7）。

## 十、常见问题（FAQ）

**Q1：运行 preprocess.py 报错"未找到 MediaPipe Tasks 模型文件"？**
新版 mediapipe 需要 `.task` 模型文件。本项目已支持首次运行自动联网下载到 `models/` 目录。若无法联网，请手动下载（报错信息会给出链接）放入 `models/`；或改用经典 API：`pip install mediapipe==0.10.9`。

**Q2：训练时显示用的是 CPU 而不是 GPU？**
说明 PyTorch 没装 CUDA 版本。到 pytorch.org 选择与你 CUDA 版本匹配的安装命令重装 torch。

**Q3：图表里中文/数字变成方框 □？**
本项目已通过 `utils.setup_chinese_font()` 自动修复。若仍出现，在 `config.PREFERRED_CN_FONT` 里手动指定一个系统已装的中文字体名（如 `"Microsoft YaHei"` 或 `"SimHei"`）。

**Q4：实时演示在 RTX 3050 上卡顿？**
把 `config.POSE_MODEL_COMPLEXITY` 改为 `0`（lite 模型），骨架提取会明显加速。

**Q5：测试集只有 4 个样本，指标可信吗？**
不可信，请以 `cross_val.py` 的留一交叉验证结果为准（见第四节第 4 步）。

**Q6：实时演示里 Reject 被识别成 Greeting？**
这是已知的数据难度问题（见 8.3），不是脚本缺陷。做演示建议优先用 Handshake / Hug 的视频；补充数据后会改善。

**Q7：运行 realtime_demo.py 后 outputs 下没有导出视频？**
确认未加 `--no-save`（默认是会导出的）；若 `--out` 指定了路径，注意它既可是目录也可是完整 `.mp4` 文件名。运行结束时控制台会打印"标注视频已保存（共写入 N 帧）"及实际路径，以此确认。

**Q8：如何做 CA-AGC 消融对比？**
把 `config.py` 里 `USE_CA_AGC` 分别设为 `True` 和 `False` 各训练评估一次，对比指标即可（见 7.7）。
